# Ananya's Birthday Website

A small, static birthday mini-game built for GitHub Pages. It uses one HTML file with inline CSS and JavaScript, plus two local JPEG images in `assets/`.

## Preview locally

Open `index.html` in a browser. No installation or build step is needed.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload everything in this folder.
2. Open the repository's **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. GitHub will show the public link after the site is deployed.

Keep the `assets` folder beside `index.html` so both gift images load correctly.
